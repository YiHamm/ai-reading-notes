# AI 論文閱讀與學習筆記

可持續擴充的繁體中文 AI 知識筆記靜態網站。

## 本機瀏覽
直接開啟 `index.html` 即可。也可以執行 `python -m http.server 8000`，前往 `http://localhost:8000`。

## GitHub Pages 部署
1. 在 GitHub 建立公開 Repository，例如 `ai-reading-notes`。
2. 將本專案所有檔案上傳至 Repository 根目錄。
3. 到 `Settings` → `Pages`，在 `Build and deployment` 選擇 `Deploy from a branch`。
4. 選擇 `main` 分支與 `/ (root)`，儲存並等待部署。
5. 公開網址通常為 `https://<你的帳號>.github.io/<Repository名稱>/`，請以 GitHub Pages 顯示的實際網址為準。

## 擴充內容
請先閱讀 `AGENTS.md`，再複製 `notes/` 中既有文章，並於首頁新增卡片。
